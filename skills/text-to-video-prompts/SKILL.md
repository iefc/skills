# 文生视频提示词

把故事意图写成可观察、有先后因果、可检查连续性的画面与声音指令。优先保证看得清“谁在何处做了什么、引起什么结果”，再增加风格修饰。本技能只交付文本，不自动生成视频、付费调用、重抽或发布。

## 模型无关与输入模式边界

本技能面向通用纯文生视频，不绑定模型、厂商或生成平台。社区项目仅作方法参考；输入数量、素材格式、引用语法、音频能力与生成参数均由当前模型/入口决定。

纯文本任务只使用文字，不虚构已上传的图片、视频或音频。用户仅提到作品或风格，不等于已提供可引用素材。若用户实际提供素材并要求参考，先确认授权和入口支持，再列“素材标识｜仅继承的特征｜不继承的内容”。首尾帧、参考视频编辑/延长、分镜图转视频等属于其他输入模式，不冒充纯文生能力。

仅在用户明确使用相关平台、已有素材或需要追溯社区来源时，按需读 [社区资料附录](references/seedance-notes.md)；无需读取附录即可执行本技能的通用流程。

案例原帖、社区复测与本次新提示词是三种证据。社区对原提示词的稳定性描述，不能外推为改编提示词或跨模型的成功承诺；未经另行授权不为验证而自动重抽。

## 1. 接收输入与锁定当前版本

先读本次需求、已有脚本和最新反馈，区分用户硬要求、可协商项、创作建议与尚未确认的假设。最新明确修改覆盖旧条款；不能把曾讨论过的所有版本叠加使用。

只集中澄清影响结构的少量问题：主题与目的、受众、目标时长、横竖构图、写实或风格化、有无对白音乐、是否必须单段生成、输入是否纯文本、目标模型/入口及预算限制。已提供的不要重问；只写提示词时不要索取账号或密钥。

信息不足但可推进：用中文、单一核心主体、少量场景、一个清楚变化与结尾作为可改默认；明确列出假设，不擅定模型、秒数、分辨率或付费预算。尚无主题时先给2—3个实质不同的方向及生成难点，不把未选方案当定稿。热点与史实需要真实依据，不把创意改编当事实，不保证流量。

**默认不继承历史项目的题材、人物、片名、战争风格、画幅、时长、预算或禁词。** 写实战争、奇幻动作、科普、生活故事应分别服务于当前目标。

## 2. 先排故事与时间，再写提示词

用一句话锁定“起始状态→触发事件→关键行动→对方或环境回应→结果”。将目标时长分给必要节点，每个时间窗优先一个主要动作，留出接触、反应和收束时间。时间标注是叙事目标，不保证模型精确遵守。

- 为复杂动作写出“准备→发生→接触/承接→结果”。例如跃起后，承载物先抵达脚下，双脚稳定接触，再加速离开；不能只写“起飞成功”。
- 攻防不能用一片光效代替：写清发起、轨迹、对手躲避/格挡/受影响、双方新位置。多回合必须各有可辨回应。
- 跨地点先交代离开的原因、方式与到达状态。明确切镜可以省略赶路，不能省略关键因果；连续镜头内不能无缘无故变位。
- 镜头过密时，先压缩重复旅行与重复建立镜头，把时间让给关键动作；不靠更长形容词或更密闪切挽救。不能容纳时提出延长、简化、分段的取舍，改变硬要求前先确认。
- 用户要求完整、不拆分：交付一份完整时间线。**完整提示词不等于一镜到底，也不等于已确认平台支持单次生成该时长。** 未知上限如实说明，不擅拆段。
- 只有用户接受分段时才附跨段交接：人物、服装、器械、方位、光线及前段结束/后段开始状态。文字不能保证跨次生成同脸或同一音乐；实际参考输入能力须另核实。

## 3. 建立连续性账本

| 维度 | 必须写清的内容 |
|---|---|
| 主体 | 核心角色数量，稳定外形、年龄感、发型、服装、体型；攻守角色分别命名 |
| 道具 | 数量、持有者、所在位置；每次召来、交接、收起、损毁的前后状态 |
| 空间 | 地点主轴、进出路径、人物相对朝向、目标位置；新机位先建立关系 |
| 动作 | 起止姿态、接触点、受力、重量、速度变化与环境反馈 |
| 视觉 | 主光方向、时段、材质、尺度参照、场景固定结构 |
| 声音 | 环境底声、动作拟音、对白、配乐的进入、让位与结束 |

例如同一件道具由脚下转入手中，先写离开脚下和回收过程，不允许手中额外复制一件。人物落地后要面对目标，给双方面向与位置，不只写“帅气降落”。需要变装时建立清楚节点并固定身份；不需要时不额外加入。

方向不是全片机械固定的“永远左向右”：同一镜头与同一组轴线保持连续，转入新空间用建立镜头重置关系，避免无解释反转。

## 4. 将抽象观感转成画面与声音

- 规模感：远景建立数量与地形，中景说明群体协作，近景呈现关键器械或动作；利用前中后景、遮挡、视差和参照物，避免复制人群与背景滑移。
- 速度感：可辨主体、加速过程、近快远慢视差、衣料与气流反馈、同步掠过声；不要缩成无法辨识的小点。现实场景遵守物理，奇幻效果也保持本片内部因果。
- 重量感：接触前减速/蓄力，接触时支撑或冲击，接触后衣物、碎屑、灰尘等反馈。巡航姿态与落地屈膝是两个阶段，不要混写。
- 镜头：每个时间窗指定景别、机位和一种主运动；切镜有叙事作用。避免同镜同时要求环绕、俯冲、拉远又极近特写。
- 声音：环境声维持空间，拟音绑定触发动作；对白给说话人、短句、时点和情绪，重要拟音与对白出现时音乐让位。音乐写蓄势、推进、高潮、余韵，不只写“燃”。无对白与有对白不能并存；多段配乐衔接仅为设计目标。

### 按题材调整，而不是全片套电影感

风格先服务用途。生活纪实可用适度手持、自动曝光变化和日常小动作；广告要分别锁住人物与产品外观，并安排可见的使用动作与结尾展示；对白剧情要标明语言、说话人、行动后的反应与停顿；制作/变化过程要先声明不变项，再写每步可见变化。只有当前题材确实需要时才采用这些方法，不把“抖动”“胶片颗粒”“大场面”当质量通用词。

镜头情绪或反转要落在能看见的结果上：观众最终看到什么变化、谁如何回应，而不是只写“震撼”“惊喜结局”。必要时给简化版和更复杂版的取舍建议，但用户要求完整定稿时仍明确一个主交付版本。

## 5. 交付结构

按阶段交付：主题澄清或方向探索阶段，只给必要问题、候选方向与标注假设的结构建议，不硬出完整提示词。只有进入最终交付或修订完整提示词阶段，才先用几句话说明本版关键取舍和未确认项，再给一个可独立复制的完整代码块。不要让用户自行拼补丁或同时保留互相冲突的旧版。需要分镜表时，先给“时间｜画面与动作｜镜头｜声音”，并确保与完整提示词一致。

完整提示词按以下顺序组织，可合并标题但不要缺漏：

1. **输入基准与目标**：纯文本/实际提供的素材、目标时长、构图、风格与声音；明确0秒开场状态及结尾目标。纯文本时不编造参考图片和素材引用。
2. **主体与世界绑定**：当前故事需要的身份、外形、道具数量、场景结构、光线和空间关系。
3. **分时段动作与声音**：连续覆盖目标总时长，逐段写起点、主动作、结果、景别/主运镜、同步声音。
4. **转场与收束**：地点跳转依据、运动衔接、最终状态和声音结束，不在结尾突然另开支线。
5. **一致性与限制**：仅保留本项目相关边界。先用正向行为定义成功，再用简短禁项防关键错误；字幕、对白、破坏、血腥、风格等按当前需求和适用安全要求处理，不把旧项目限制全盘套用。

模型名称、时长、比例、分辨率、音频开关等是待核实的入口设置，不是写进文本就已设置。不要跨版本搬用参数、参考语法或上限；需要给具体参数时查当前官方文档。提示词不得声称能移除平台水印、保证同脸、保证准确口型或实现全部镜头。

## 6. 根据成片反馈迭代

若提供了可实际查看的视频，通过可用的视频分析能力检查后，按时间码记录“看到/听到的现象→对应旧指令→拟修改内容”；无法检查就说明依据仅来自用户描述，不编观片结论。区分用户反馈、实际观察和原因假设，不能把推测当模型内部机制。

优先修复自己的矛盾指令：旧版要求不破坏，新版要求局部破坏，就替换旧边界；旧版无对白、新版指定喊话，就重写声音约束。每次交付完整替换稿，明确目标变化，避免不断累加限制。

只按当前授权交付文本。用户说某次结果满意，只表示该次认可，不代表本技能或某模型普遍通过实测；不得虚构耗时、费用、成功率或已经生成。

## 7. 交付前自检

- [ ] 最新要求、可协商项与默认假设已区分，未误继承旧版本。
- [ ] 时间连续、无重叠缺段，关键动作有完成与回应的余量。
- [ ] 主体与道具数量稳定；姿态、朝向、持物变化有交代。
- [ ] 空间、切镜、光线、尺度与动作因果一致，无凭空跳位。
- [ ] 运镜不互相冲突；速度、重量、规模均有具体视觉依据。
- [ ] 环境、拟音、对白、音乐互不矛盾，关键声音有触发点。
- [ ] 分镜表与完整提示词一致；输出可独立复制。
- [ ] 叙事目标与模型能力分开；未擅自生成、计费或声称实测。

## 中性示例：雨后阳台浇花

仅为结构演示，假设本次用户已选目标6秒、竖屏、有环境声、无对白的日常场景；这些数字与构图不是默认值、入口设置或能力承诺。

```text
【输入与目标】纯文本创作，目标6秒竖屏生活短片。0秒直接进入雨后阳台，一位成年人准备给花盆补少量水；结尾完成浇水并收手。
【绑定】同一人穿浅色长袖，右手持唯一一只白色小水壶；一只陶盆置于木桌中央，植物叶片带雨珠。柔和晨光从画面左侧进入，阳台与盆的位置固定。
【时间线】
0—2秒：侧面中景固定机位。人物将壶嘴移到盆沿内侧，另一手扶稳盆边，水壶尚未倾斜。保留远处鸟鸣与衣料轻响。
2—4秒：同侧切近景，右手缓慢倾壶，细水流落在土面而非叶片外侧；土壤局部逐渐变深。同步细水落土声，环境声不断。
4—6秒：保持同一机位，水壶回正，水流减细后停止；壶嘴离开花盆，人物放松扶盆的手。末尾停留在湿润土面与轻晃叶片上，只留鸟鸣。
【连续性与限制】动作顺序为移壶、倾倒、回正止水、移开；手与壶数量不变，水流连接壶嘴与土面。无配乐、对白或字幕，不突然更换植物、陶盆与天气，不用转场遮住倒水动作。
```

## 改编示例：器械推进的动作因果

以下为方法示例，概括器械协同场景，不是原始聊天、固定项目风格或已测试效果。假定本次用户已选择8秒横屏、写实、有声、单场景，目标是交代“铺桥后推车”，不是复刻整场战役。

```text
【目标与输入】
纯文本创作，目标8秒横屏写实短片，允许切镜，有环境声与配乐。0秒直接进入石墙外的浅旱壕，结尾木车完成过桥；不加片头。
【主体与场景】
一组穿深色布甲的成年搬运者、一座木桥板、一辆四轮木车。壕沟、对岸石墙与道路位置固定，阴天散射光，木材粗糙。人群沿道路向石墙方向前进。
【时间线】
0—3秒：侧面中远景，机位固定。木桥已搬到壕边，数人协力完成最后下放，桥板两端落在两岸支点，木架受力后稳定。同步粗绳摩擦、木板落地与短促脚步声。
3—6秒：沿原轴线切低机位侧拍，木车前轮先上桥，桥板轻微受压但支点不滑移；后轮再跟进。镜头缓慢平移，近处车轮与远处石墙形成视差。同步木轮滚动与桥板吱响，低鼓压低。
6—8秒：同侧中景，后轮离开桥板，整车到达对岸后减速停稳，搬运者随行站定。保留短暂静止确认动作完成，木轮余响后只留风声。
【连续性与限制】
顺序始终是桥板落稳、车轮上桥、后轮离桥、停稳。不增加车辆，不让桥板悬空或车轮穿板，不用烟尘和闪切遮住承重接触。音乐仅低鼓与低弦，无对白与字幕，不盖住木材拟音。
```
