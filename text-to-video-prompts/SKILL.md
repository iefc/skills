# 通用文生视频提示词

将主题、故事或反馈转成可直接复制的完整视频提示词：主体清楚，动作有因果，空间与道具连续，画面和声音对应。不绑定模型、平台、题材或固定时长。本文件包含全部方法，无需额外参考文件即可执行。只交付文本，不自动生成视频、付费、重抽或发布。

## 1. 确认目标与当前版本

先读需求、已有稿和最新反馈，区分硬要求、可协商项、建议与假设。最新明确修改覆盖旧条款，不把不同版本的限制叠加。

仅澄清影响结构的重要缺项：主题、目的与受众，目标时长、横竖构图、风格，有无对白/音乐，是否必须单次生成，输入模式、目标模型/入口及预算。已提供的不重问；只写提示词不索取账号或密钥。不必逐项盘问，可逆细节明确默认后推进，重要取舍才请用户决定。

主题未定时给 2—3 个实质不同方向，说明看点和生成难点，不将候选当定稿。可采用中文、单一核心主体、少量场景、一个清楚变化和结尾作为可改默认；不擅定模型、秒数、分辨率、收费预算。热点、史实、数字须有真实依据，创意改编明确标识，不保证流量。

不继承历史项目的战争风格、人物、画幅、时长、金额或禁词。一般任务不强制电影化，也不强制无对白、无破坏或一镜到底。

### 交互流程

1. **明确目标**：广告、短剧、MV、科普、Vlog、打斗、产品、过程变化等。
2. **了解素材**：是否有图片/视频/音频；纯文生则不做素材假设。
3. **选择控制结构**：一镜到底 / 时间轴分镜 / 身份或产品锁定 / 复杂动作编排 / 需要分段交接。
4. **构建提示词**：按第四节公式与第六节输出块组织。
5. **自检**：时长与复杂度匹配、无指令冲突、音频有触发、负向清单在末尾全局生效。
6. **必要时给变体**：简版与复杂版各一句取舍说明，最终只交付一个主版本。

## 2. 先设计可见故事与时间预算

一句话说明：起始状态、触发事件、关键行动、对方或环境回应、最终结果。所有情绪与反转落到观众能看见或听见的变化，而非只写「震撼」「高级」「燃」。

### 时间轴规则

- 每个时间窗优先**一个主动作**，写清起点与结束状态，预留接触、反应和收束时间。连续覆盖目标时长，不重叠、不缺段；时间码是叙事目标，不保证模型精确遵守。
- 段长优先 2—5 秒。纪实可更短，广告约 3 秒一段；无音频驱动时不要写到 0.01 秒级精度（纯文生有效分辨率大约 0.5 秒）。
- 时间写成首尾相接的闭区间（如 `0-4s` 接 `4-8s`），总和等于声明时长；只写总时长不写分段时，后半段容易漂。
- 复杂动作拆成准备、发生、接触/承接、结果。例如跳起后，承载物先抵达脚下，双脚稳定接触，再加速离开。
- 攻防要有发起、轨迹、躲避/格挡/受影响、双方新位置；多回合各有回应，不能用光效掩盖动作。
- 跨地点交代离开的原因、方式和到达状态。切镜可省赶路，不可省关键因果；连续镜头不能无故变位。
- 内容过载先减重复旅行与建立镜头，再讨论延长、简化或分段。不能通过堆形容词或闪切挽救，也不能未经同意改变硬要求。
- 用户要求完整、不分开时，给一份完整时间线，不擅拆段。完整提示词不等于一镜到底，也不等于平台支持单次生成该长度。只有用户接受分段，才增加跨段人物、服装、道具、方位、光线及首尾状态交接；文字不保证跨次同脸、同音乐。

## 3. 建立连续性账本

| 维度 | 锁定与检查内容 |
|---|---|
| 主体 | 人物数量、身份、外形、年龄感、发型、服装、体型；互动角色分别命名 |
| 道具 | 数量、持有者、位置；召来、交接、回收、损毁的前后状态 |
| 空间 | 地点轴线、进出路径、相对位置与朝向，目标位置；换空间先建立关系 |
| 动作 | 起止姿态、接触点、受力、重量、速度变化、环境反馈 |
| 视觉 | 主光、时段、材质、尺度参照、固定场景结构 |
| 声音 | 环境底声、动作拟音、说话人、音乐进入/让位/结束 |

同一道具从脚下转入手中，须先离开脚下并回收，不能额外复制一件。落地应面对目标，不能只写「帅气降落」。变装仅在需要时设计明确节点并保持身份。同镜头和同组轴线保持方向连续，新空间用建立镜头重置，不机械要求全片永远左向右。

**不要在每个时间段重写服装发型**——身份写在全局固定块一次，并声明全程不变；逐段重申反而诱发段间外观突变。

### 参考素材：继承 / 不继承

若用户确实提供并允许使用素材，且当前入口支持：

1. 给每张/每段素材稳定标识（如 `@图1`、`Image1`，语法按入口实际要求）。
2. **继承清单**逐条枚举：脸型、五官、发色、身材比例、服装单品、产品几何与颜色等——不要只写「保持一致」。
3. **不继承清单**单独写明：背景、房间、家具、姿势、构图、画角、原始光线、文字、分割布局等。
4. 转头、遮挡、快速运动等高漂段，可短句重申同一身份，勿整段复制外形描写。

提到作品风格不等于提供了素材。首尾帧、参考视频编辑/延长、分镜图转视频属于不同输入模式，不能冒充纯文生。纯文生只使用文字，不虚构参考图片、视频、音频或已上传素材。

## 4. 提示词结构公式与视听指令

### 基本公式

```text
[主体/人物设定] + [场景/环境] + [动作/运动] + [运镜] + [分时段] + [转场/特效] + [声音] + [风格/氛围]
```

超过约 8 秒优先分时段；短于 8 秒也可分段，若单段能写清因果则不必硬拆。

### 镜头与物理反馈

每段指定景别、机位和一种主运镜，切镜有叙事作用。避免同镜同时环绕、俯冲、拉远又极近特写。

| 基础运镜 | 说明 |
|---|---|
| 推 / 慢推 | 镜头向主体靠近 |
| 拉 / 后拉 | 镜头远离主体 |
| 左摇 / 右摇 | 水平旋转 |
| 上摇 / 下摇 | 垂直旋转 |
| 跟随 / 跟拍 | 跟随主体移动 |
| 环绕 | 围绕主体旋转 |
| 一镜到底 | 全程无剪辑的连续镜头 |

| 常用景别 | 说明 |
|---|---|
| 极致特写 | 眼睛、嘴或小物件细节 |
| 特写 | 脸部充满画面 |
| 中近景 | 头与肩 |
| 中景 | 腰部以上 |
| 全景 | 完整人物 |
| 远景 / 建立镜头 | 完整环境 |

可用英文机位词夹在段头括号里（如 `Ground-level Low Angle`、`Dynamic Tracking`、`POV`），正文用工作语言；混写往往比全译更稳。

规模用远景地形与数量、中景协作、近景关键动作，配合前中后景、遮挡、视差和参照物。速度用可辨主体、加速过程、近快远慢视差、气流衣料与同步掠过声。重量用接触前蓄力/减速、接触时支撑冲击、接触后灰尘碎屑或衣料反馈。写实守物理，奇幻也守内部因果。

### 声音设计

环境声维持空间，拟音绑定触发动作。对白标语言、说话人、短句、时点、情绪与对方反应。重要对白和拟音出现时音乐让位；音乐写蓄势、推进、高潮、余韵，不仅写「振奋」。有对白与无对白不冲突叠加。模型不支持生成音频时，将声音注明为制作意图而非承诺。

### 按用途选择表达

| 用途 | 写法要点 |
|---|---|
| 生活纪实 / UGC | 日常小动作、真实光线；必要时适度手持，不盲加抖动 |
| 产品广告 | 分别锁人物与产品外观；可见使用过程 + 结尾展示；避免标识/形状/颜色漂移 |
| 对白剧情 | 动作引发反应，给回应与停顿，不仅让角色念台词 |
| 制作或变化过程 | 先声明不变项，再写每一步可见变化，避免凭空出现完成品 |
| 动作与打斗 | 生物力学、接触点、连招链；禁待机摆架子、瞬移跳位；镜头绕接触点，不越轴 |
| 奇幻 / 史诗 | 每个实体单独定义块；尺度用参照物与低角度，不用「巨大」堆砌 |
| 音乐卡点 | 切点、动作落点对齐节拍；无音频输入时不要伪精确到百分之一秒 |
| 一镜到底 | 路径、进出、朝向连续写清；声明全程无切 |
| 科普 / 过程可视化 | 每段一个可见变化；对比前后状态；风格用可度量词 |
| 风格锁定（动漫等） | 可度量参数 + **邻近风格排除清单**，否则易塌成泛 CG 脸 |

胶片颗粒、大场面、电影感不是所有作品的质量通用词。需要时解释简化版与复杂版的取舍，最终明确一个主交付版本。

### 可选风格修饰（按需追加，勿堆砌）

- 画面：浅景深、明确画幅与帧率意图、水墨/动漫/超写实、冷暖对比等——只选与本案相关的。
- 氛围：紧张、治愈、史诗、纪录片克制、喜剧夸张等——落到可见行为与光线，不只贴标签。
- 音频：BGM 走向、关键拟音、口吻；有参考素材时写清参考的是音色、节奏还是整段 BGM。

## 5. 纯文生与模型适配边界

模型名称、时长、比例、分辨率、音频开关是入口设置，不是写进提示词就已设置。需要具体参数时核对当前官方资料，记录模型/入口/版本与日期，不跨版本照搬社区的上限、数量、格式、费用或政策。不承诺移除水印、同脸、准确口型或全部镜头实现。

平台若使用 `@` 等引用语法：必须说明**每个引用参考什么**（首帧、人物、运镜、动作、特效、节奏、音色、BGM），禁止只写「参考 @视频1」。具体语法只用于真实存在、入口认可的素材。其他模型使用其自己的语法。

原案例、社区复测和新提示词是三类证据，不能把原帖标签或复跑效果当作本次新稿/跨模型已验证，不为验证而未经授权重抽。

## 6. 输出可独立使用的完整提示词

澄清或探索阶段只给必要问题、候选方向与明确假设，不硬出完整稿。最终或修订交付先简述关键取舍与未确认项，再给一个完整代码块；不让用户拼零散补丁，不并列冲突旧版本。

完整提示词按四块组织（可合并标题，但不缺必要信息）：

```text
【全局】
用途、输入模式、目标时长、构图、整体风格与声音意图；0 秒开场状态与最终结果。

【固定】
全片不变的人物/产品外形、道具数量与归属、固定空间、光线与尺度；
若有参考素材：标识｜继承清单｜不继承清单。

【时间轴】
每段：时间窗｜景别/机位/主运镜｜起点状态 → 一个主动作 → 接触与回应 → 结果｜环境/拟音/对白/配乐变化。
段与段显式交接状态；按已确认时长连续覆盖，不用模板占位符当最终稿。

【约束】
正向成功标准 + 与本项目相关的少量禁项（负向清单放在末尾全局生效，不塞进某一段）；
不沿用无关旧禁令。
```

用户要分镜表时，先给「时间｜画面与动作｜镜头｜声音」，确保与完整提示词一致。字幕、对白、破坏、血腥、风格按当前需求与适用安全要求处理，不全盘复制案例约束。

## 7. 依据反馈修订

有视频时，先通过实际可用的视频分析能力检查，才记录时间码和视听观察。无法检查则明确仅依据用户描述，不编观片结论。区分用户反馈、实际观察和原因假设，不把猜测当模型内部机制。

优先修复矛盾：最新要求局部破坏就替换旧版无破坏，最新指定喊话就替换无对白。每次交付完整替换稿，解释目标变化，避免不断堆限制。一次满意只代表该次认可，不证明技能通用成功率；不虚构生成结果、耗时、费用或实测。

### 修订时可用的检查维度

| 维度 | 观察什么 |
|---|---|
| 节拍顺序 | 要求的关键节拍是否按序出现、时长是否被挤没 |
| 身份/产品 | 脸、服装、几何、颜色、标识是否跨切镜漂移 |
| 状态交接 | 道具、手、门、天气是否只经可见动作变化 |
| 动作/物理 | 主动作是否完成；肢体/物体是否瞬移、合并或数量突变 |
| 空间连续 | 朝向、门槛哪一侧、运动方向是否越轴错乱 |
| 声音 | 对白/环境/拟音是否与画面触发对齐 |
| 输出卫生 | 时长、画幅、字幕、水印、多余文字是否符合约定 |

每个问题尽量对应一处可控输入（某一时段、某一固定块、某一素材用途），做有界修改后重交完整稿。

## 8. 常见错误（优先避免）

1. **模糊参考**：有素材却不写参考的是运镜、动作、特效还是节奏。
2. **指令冲突**：同一段同时要求固定镜头与环绕、既静又剧烈甩镜。
3. **内容过载**：4—5 秒塞过多场景或两个主动作各做一半。
4. **只写总时长不写分段**：后半段漂移；或时长声明与分段总和不一致。
5. **逐段重写外形**：诱发换脸换装；应写在固定块。
6. **忽视音频**：无环境声、无拟音触发、对白与音乐抢位。
7. **负向清单放错位置**：硬限制应在末尾全局块，塞进单段往往只对该段生效或被忽略。
8. **把情绪词当画面**：只写震撼/高级/燃，没有可见状态变化。
9. **伪造素材或能力**：纯文生却写已上传图；或把入口参数当成提示词已生效。
10. **把案例效果当本次验证**：原帖、复测与新稿三类证据不混用。

## 9. 交付前自检

- 当前硬要求、默认假设、最新覆盖关系清楚，未误继承旧项目。
- 时间连续，关键动作与回应留足余量；完整稿没有要求用户自行填的占位符。
- 主体与道具数量稳定，持物、姿态、朝向变化可追踪；固定块与时间轴不互相打架。
- 空间轴线、光线、尺度、接触与因果成立，切镜不掩盖缺失动作。
- 运镜无冲突，声音有触发点且互不矛盾；负向清单在末尾且与本案相关。
- 分镜表和完整提示词一致，可独立复制。
- 文本意图与平台能力分开，未伪造素材、验证、生成或授权。

## 示例：雨后阳台浇花

仅演示结构。假设本次用户已选择 6 秒、竖屏、有环境声、无对白；这些不是默认值、入口设置或能力承诺，示例未经视频生成验证。

```text
【全局】纯文本创作，目标 6 秒竖屏生活短片。0 秒进入雨后阳台，一位成年人准备给花盆补少量水，结尾完成浇水并收手。

【固定】同一人穿浅色长袖，右手持唯一白色小水壶；一只陶盆位于木桌中央，叶片带雨珠。晨光从左侧进入，阳台和盆的位置固定。全程人物、服装、壶与盆数量不变。

【时间轴】
0—2秒（侧面中景，固定机位）：壶嘴移到盆沿内侧，左手扶稳盆边，壶未倾斜。远处鸟鸣、衣料轻响。
2—4秒（同侧近景）：右手缓慢倾壶，细水流落在土面，土壤局部逐渐变深。同步落水声，环境声不断。
4—6秒（机位不变）：水壶回正，水流减细后停止；壶嘴离开，左手松开盆边。停留湿润土面和轻晃叶片，只留鸟鸣。

【约束】移壶、倾倒、回正止水、移开的顺序清晰；手与壶数量不变，水流连接壶嘴与土面。无音乐、对白、字幕，不换植物、陶盆和天气，不用转场遮住动作。
```
