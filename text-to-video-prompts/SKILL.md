# 通用文生视频提示词

将主题、故事或反馈转成可直接复制的完整视频提示词：主体清楚，动作有因果，空间与道具连续，画面和声音对应。不绑定模型、平台、题材或固定时长。本文件包含全部方法，无需额外参考文件即可执行。只交付文本，不自动生成视频、付费、重抽或发布。

写作时同时满足两层：**写清楚故事**，以及**写成模型做得出的画面事件**（可辨执行者、可核验结果、节拍密度可控）。

## 1. 确认目标与当前版本

先读需求、已有稿和最新反馈，区分硬要求、可协商项、建议与假设。最新明确修改覆盖旧条款，不把不同版本的限制叠加。

仅澄清影响结构的重要缺项：主题、目的与受众，目标时长、横竖构图、风格，有无对白/音乐，是否必须单次生成，输入模式、目标模型/入口及预算。已提供的不重问；只写提示词不索取账号或密钥。不必逐项盘问，可逆细节明确默认后推进，重要取舍才请用户决定。

主题未定时给 2—3 个实质不同方向，说明看点和生成难点，不将候选当定稿。可采用中文、单一核心主体、少量场景、一个清楚变化和结尾作为可改默认。热点、史实、数字须有真实依据，创意改编明确标识，不保证流量。

不继承历史项目的战争风格、人物、画幅、时长、金额或禁词。一般任务不强制电影化，也不强制无对白、无破坏或一镜到底。

### 数字的两类边界

- **规格类数字（禁止擅定）**：模型名称、平台入口、时长上限、分辨率、帧率、收费与预算——这些是入口设置，不属于提示词，也不是「一切数字都不写」。
- **叙事类量化（鼓励写具体数）**：排数、面牌数、器械具数、骑数、烽燧数与纵深层数。具体数字比「数十 / 大批 / 黑压压」更能锁定画面体量。

竖屏约 480p 时可复用量级参考（按需裁剪，非强制默认）：盾墙不少于 8 排、每排约 12 面牌；砲位不少于 20 具；云梯 3 架同靠；撞木队约 30 人；骑兵 12 骑分两列；纵深不少于 3 层。

### 交互流程

1. **明确目标**：广告、短剧、MV、科普、Vlog、打斗、产品、过程变化、大场面等。
2. **核对节拍预算**：以「秒数 ÷ 5」为默认密度；超默认则先分段或降密，不硬塞进单条生成稿。
3. **了解素材**：是否有图片/视频/音频；纯文生则不做素材假设。
4. **选择控制结构**：一镜到底 / 时间轴分镜 / 身份或产品锁定 / 复杂动作编排 / 需要分段交接。
5. **构建提示词**：按第四节公式与第六节输出块组织；群体动作落锚人物，每拍给结果证据。
6. **自检**：时长与复杂度匹配、无指令冲突、音源白名单、负向清单在末尾全局生效。
7. **必要时给变体**：简版与复杂版各一句取舍说明，最终只交付一个主版本。

## 2. 先设计可见故事与时间预算

一句话说明：起始状态、触发事件、关键行动、对方或环境回应、最终结果。所有情绪与反转落到观众能看见或听见的变化，而非只写「震撼」「高级」「燃」。

多节拍叙事时，先列「节拍因果链」：每一拍必须能指出「上一拍的哪个动作导致这一拍的开始」；再按节拍预算决定单条生成还是分段生成。

### 节拍预算（默认密度，非铁律）

「目标秒数 ÷ 5」（向下取整）是**默认预算**，用来估计单条生成稿能扛住的主动作链密度；不是物理定律，也不是不可讨论的上限。

- **默认用法**：15 秒默认按约 3 条主动作链规划，30 秒约 6 条。单条生成稿优先落在默认预算内。
- **可上调的情形**（须显式说明理由）：题材极简（单人单空间、无群戏）、一镜到底且动作链本身短、用户指定更强模型/入口且接受质量风险。上调后仍须保证每拍有锚人物（若有群体）与结果证据，不得靠闪切凑密度。
- **可下调的情形**：群戏、器械、多地点、身份强锁定、历史考据、带复杂音频——宁可少于默认，也勿贴着默认硬塞。
- **超默认时的处置（必须二选一或组合，禁止假装仍可单次塞进）**：
  1. **分段生成**：一条提示词只承担 1—2 个主动作链；段间给「交接三要素」（同一空间锚点、同一光向、前段末帧状态）。
  2. **降密**：合并节拍、删建立镜头/重复旅行、把次要拍改成前一拍的结果余波，而不是把每拍压成静帧。
  - 不得用「闪切 / 烟尘 / 火光」冒充节拍过渡。
- 单个约 5 秒拍内禁止写「先 A 再 B 最后 C」三段式；一拍只允许「起点状态 → 一个主动作 → 接触/回应 → 结果」这一条链。
- 叙事节拍明显多于默认预算时，交付物应至少包含：**总时间轴（叙事用）＋ 分段或降密后的生成稿**，并写明是否接受分段。不得把超默认密度的多拍塞进一条提示词后声称「可单次生成」。
- 用户坚持单条且超默认：说明退化风险（每拍易变静态插图），给出分段方案与降密方案供选，仍不擅自改硬要求的题材与结局。

### 时间轴规则

- 每个时间窗优先**一个主动作**，写清起点与结束状态，预留接触、反应和收束时间。连续覆盖目标时长，不重叠、不缺段；时间码是叙事目标，不保证模型精确遵守。
- 段长优先 2—5 秒。纪实可更短，广告约 3 秒一段；无音频驱动时不要写到 0.01 秒级精度（纯文生有效分辨率大约 0.5 秒）。
- 时间写成首尾相接的闭区间（如 `0-4s` 接 `4-8s`），总和等于声明时长；只写总时长不写分段时，后半段容易漂。
- 复杂动作拆成准备、发生、接触/承接、结果。例如跳起后，承载物先抵达脚下，双脚稳定接触，再加速离开。
- 攻防要有发起、轨迹、躲避/格挡/受影响、双方新位置；多回合各有回应，不能用光效掩盖动作。
- 跨地点交代离开的原因、方式和到达状态。切镜可省赶路，不可省关键因果；连续镜头不能无故变位。
- 内容过载先减重复旅行与建立镜头，再讨论延长、简化或分段。不能通过堆形容词或闪切挽救，也不能未经同意改变硬要求。
- 用户要求完整、不分开时：可给一份完整叙事时间轴；若节拍明显超过默认预算，叙事时间轴与生成用稿（分段或降密）必须分开交付，并标明哪份用于单次生成。完整提示词不等于一镜到底，也不等于平台支持单次生成该长度。只有用户接受分段，才增加跨段人物、服装、道具、方位、光线及首尾状态交接；文字不保证跨次同脸、同音乐。

### 段间接力与硬切禁令

- 段内禁止硬切与跳景；一个镜头内不得切换景别或空间。
- 每拍必须成对写出「段末状态句」与「下一段首状态句」，两句话描述同一画面事实（同一片烟尘位置、同一光向、同一门洞角度），作为接力锚点。
- 不得在上一拍动作未完成时开出下一拍；若必须提前，需显式标为「交叠」并给出交叠时长（不少于 1 秒）。
- 「一个主动作」≠「一个静态机位摆拍」：机位可固定，但主动作链必须含可见发力、接触与结果，禁止只写场面布置。

## 3. 建立连续性账本

| 维度 | 锁定与检查内容 |
|---|---|
| 主体 | 人物数量、身份、外形、年龄感、发型、服装、体型；互动角色分别命名；群体动作另设锚人物 |
| 道具 | 数量、持有者、位置；召来、交接、回收、损毁的前后状态 |
| 空间 | 地点轴线、进出路径、相对位置与朝向，目标位置；换空间先建立关系 |
| 动作 | 起止姿态、接触点、受力、重量、速度变化、环境反馈；结果证据形式 |
| 视觉 | 主光、时段、材质、尺度参照、固定场景结构 |
| 建制与工艺 | 建筑形制、材料工艺、甲胄制式、器物结构、称谓与旗号；写明「是什么 / 不是什么」 |
| 声音 | 环境底声、动作拟音、说话人、音乐进入/让位/结束；音源白名单 |

同一道具从脚下转入手中，须先离开脚下并回收，不能额外复制一件。落地应面对目标，不能只写「帅气降落」。变装仅在需要时设计明确节点并保持身份。同镜头和同组轴线保持方向连续，新空间用建立镜头重置，不机械要求全片永远左向右。

**不要在每个时间段重写服装发型**——身份写在全局固定块一次，并声明全程不变；逐段重申反而诱发段间外观突变。

### 设定锁表（历史 / 架空 / 科幻等有世界观的题材必填）

- 在固定块列出建制与工艺：例如「门道为过梁式排叉柱撑顶的方形门道，不用砖拱券」「城墙为夯土版筑可见横向夯层与收分，有马面与女墙垛口」。
- 每个镜头首句复述三条最短锚点：同一座城的材料与高度、同一空间锚点（门洞 / 城墙位置）、同一光向。跨段不重述整段设定，只复述三锚点。
- 同一建筑在同一作品内不得出现两种形制（如先拱形黑洞、再矩形门框、再砖拱券）。

### 参考素材：继承 / 不继承

若用户确实提供并允许使用素材，且当前入口支持：

1. 给每张/每段素材稳定标识（如 `@图1`、`Image1`，语法按入口实际要求）。
2. **继承清单**逐条枚举：脸型、五官、发色、身材比例、服装单品、产品几何与颜色等——不要只写「保持一致」。
3. **不继承清单**单独写明：背景、房间、家具、姿势、构图、画角、原始光线、文字、分割布局等。
4. 转头、遮挡、快速运动等高漂段，可短句重申同一身份，勿整段复制外形描写。

提到作品风格不等于提供了素材。首尾帧、参考视频编辑/延长、分镜图转视频属于不同输入模式，不能冒充纯文生。纯文生只使用文字，不虚构参考图片、视频、音频或已上传素材。

## 4. 提示词结构公式与视听指令

### 基本公式

```text
[主体/人物设定] + [场景/环境] + [动作/运动] + [运镜] + [分时段] + [转场/特效] + [声音] + [风格/氛围]
```

超过约 8 秒优先分时段；短于 8 秒也可分段，若单段能写清因果则不必硬拆。先用默认节拍预算估密度，超了就分段或降密，再写公式展开。

### 锚人物原则（群体动作必须落地）

凡写群体动作（齐发、齐推、齐拽、齐喊、并进），必须同时指定 1 名可辨识的「锚人物」，并给出该人物的可执行动作细节：

- **谁**：兵种 + 一眼可辨的装束特征
- **做什么**：手 / 肩 / 腰的具体发力与姿态
- **第一个可见变化**：绳索绷直、砲梢抬起、门板错位等

群体只写体量与方向，动作细节一律挂在锚人物身上。一个约 5 秒拍只设 1 个锚人物；锚人物不得在段内换装或换位。没有锚人物的群体动词，模型常会拍成不动的道具阵。

### 结果证据（每拍必须可核验）

「结果」必须是画面上可验证的物理状态改变，只接受三种形式：

1. **形变**——断裂、塌陷、错位、洞穿（门板内塌成豁口、垛口塌出缺口）
2. **位移**——从 A 位置移到 B 位置的可见轨迹（石弹落在第三垛口、土袋入水、梯头卡进垛口）
3. **状态翻转**——由闭到开、由立到倒、由守到弃（门由紧闭到通行、守军旗由立到倾）

禁止用「冒烟、火光、尘土、人群溃退」充当结果；这些是氛围，不是结果。该结果同时是下一拍的起点，下一拍不得出现「结果已提前完成」的状态（如门已开着再去撞门、旗已插上再去夺楼）。

### 镜头与物理反馈

每段指定景别、机位和一种主运镜，切镜有叙事作用。避免同镜同时环绕、俯冲、拉远又极近特写。避免正对门 / 墙中线的完全对称构图；主体宜偏离画面中线（如 3/4 斜侧）。

| 基础运镜 | 说明 |
|---|---|
| 推 / 慢推 | 镜头向主体靠近 |
| 拉 / 后拉 | 镜头远离主体 |
| 左摇 / 右摇 | 水平旋转 |
| 上摇 / 下摇 | 垂直旋转 |
| 跟随 / 跟拍 | 跟随主体移动 |
| 环绕 | 围绕主体旋转 |
| 一镜到底 | 全程无剪辑的连续镜头 |

| 常用景别 | 说明 |
|---|---|
| 极致特写 | 眼睛、嘴或小物件细节 |
| 特写 | 脸部充满画面 |
| 中近景 | 头与肩 |
| 中景 | 腰部以上 |
| 全景 | 完整人物 |
| 远景 / 建立镜头 | 完整环境 |

可用英文机位词夹在段头括号里（如 `Ground-level Low Angle`、`Dynamic Tracking`、`POV`），正文用工作语言；混写往往比全译更稳。

规模用远景地形与数量、中景协作、近景关键动作，配合前中后景、遮挡、视差和参照物。速度用可辨主体、加速过程、近快远慢视差、气流衣料与同步掠过声。重量用接触前蓄力/减速、接触时支撑冲击、接触后灰尘碎屑或衣料反馈。写实守物理，奇幻也守内部因果。

### 低分辨率可读性分层

- 分辨率低于 720p 时，不得以「面部 / 五官差异」承载群像差异化，改用：兵种色块、甲胄形制（札甲 / 皮甲 / 布衣）、体态（高矮胖瘦、扛 / 拽 / 推 / 攀）、装束残损（断缨、缺甲、缠布、泥污血迹）、旗色与器物差异。
- 每镜头面部清晰者不超过 3 人；其余以轮廓与旗色区分。
- 体量只靠三样东西承载：旗幡密度、纵深排数、烟尘方向。禁止靠「特写堆人」或「千人千面」造规模。

### 声音设计与音源白名单

环境声维持空间，拟音绑定触发动作。对白标语言、说话人、短句、时点、情绪与对方反应。重要对白和拟音出现时音乐让位。有对白与无对白不冲突叠加。模型不支持生成音频时，将声音注明为制作意图而非承诺。多模态入口默认自带音频时，必须在约束块写音源白名单，否则易穿帮。

**音源白名单（写进约束块，末尾全局生效）**——按题材裁剪；历史冷兵器战例默认：

- 只允许：战鼓、号角、弓弦、木石撞击、甲片摩擦、马蹄、火油燃烧与竹木噼啪、人群呼喊、环境风声与水声。
- 禁止：枪炮与自动武器声、炮弹式爆炸轰鸣、马达 / 引擎 / 机械轰鸣、动物咆哮、电子音乐、现代影视爆炸音效库音。
- 历史题材火攻只写「火油燃烧、竹木爆裂的噼啪」，不写「爆炸」——「爆炸」易诱发现代音效。

卡点不要只写「同步」：给鼓型或节奏分工，并要求重击落点与该拍接触瞬间重合。例如六段可写：滚奏（准备）／行进双击（推进）／急鼓（攻坚）／一记重击接长音（破门）／最快乱鼓（混战）／三记收束（收兵）。

### 避讳词表（易诱错写法）

| 易诱错写法 | 模型实际常给出 | 改法 |
|---|---|---|
| 「门缝」/「缝隙透光」 | 缝隙被渲成贯穿发光白线 | 写「门轴崩裂、门板错位内塌、豁口」，删掉「缝」 |
| 正对门/墙中线的对称构图 | 对称接缝、渲染白线、纵向接缝 | 改 3/4 斜侧机位，明确「主体偏离画面中线」 |
| 「齐发/齐射/千军万马/黑压压」 | 群体静置，体量最小化 | 锚人物 + 具体排数与具数 |
| 「起火/火海/火光冲天」 | 火焰失控、整屏过曝 | 写火舌上限（如不超过 2 米）与燃烧范围（仅梯身上段与垛口） |
| 「奔入门内/穿过城门」 | 方向可正可反，可能生成出城 | 用画面语言：「镜头在城内一侧正对门洞，骑兵自门外亮处越入画面、向镜头纵深奔来」 |
| 「爆炸」 | 现代爆炸音效 | 火油燃烧、竹木噼啪 |

### 按用途选择表达

| 用途 | 写法要点 |
|---|---|
| 生活纪实 / UGC | 日常小动作、真实光线；必要时适度手持，不盲加抖动 |
| 产品广告 | 分别锁人物与产品外观；可见使用过程 + 结尾展示；避免标识/形状/颜色漂移 |
| 对白剧情 | 动作引发反应，给回应与停顿，不仅让角色念台词 |
| 制作或变化过程 | 先声明不变项，再写每一步可见变化，避免凭空出现完成品 |
| 动作与打斗 | 生物力学、接触点、连招链；禁待机摆架子、瞬移跳位；镜头绕接触点，不越轴 |
| 大场面 / 攻城 | 默认节拍预算估密度，超则分段/降密；锚人物 + 结果证据 + 设定锁表 + 音源白名单；叙事量化写具体数 |
| 奇幻 / 史诗 | 每个实体单独定义块；尺度用参照物与低角度，不用「巨大」堆砌 |
| 音乐卡点 | 切点、动作落点对齐节拍；无音频输入时不要伪精确到百分之一秒 |
| 一镜到底 | 路径、进出、朝向连续写清；声明全程无切 |
| 科普 / 过程可视化 | 每段一个可见变化；对比前后状态；风格用可度量词 |
| 风格锁定（动漫等） | 可度量参数 + **邻近风格排除清单**，否则易塌成泛 CG 脸 |

胶片颗粒、大场面、电影感不是所有作品的质量通用词。需要时解释简化版与复杂版的取舍，最终明确一个主交付版本。

### 可选风格修饰（按需追加，勿堆砌）

- 画面：浅景深、明确画幅与帧率意图、水墨/动漫/超写实、冷暖对比等——只选与本案相关的。
- 氛围：紧张、治愈、史诗、纪录片克制、喜剧夸张等——落到可见行为与光线，不只贴标签。
- 音频：鼓型分工、关键拟音、口吻；有参考素材时写清参考的是音色、节奏还是整段 BGM。

## 5. 纯文生与模型适配边界

模型名称、时长、比例、分辨率、音频开关是入口设置，不是写进提示词就已设置。需要具体参数时核对当前官方资料，记录模型/入口/版本与日期，不跨版本照搬社区的上限、数量、格式、费用或政策。不承诺移除水印、同脸、准确口型或全部镜头实现。

平台若使用 `@` 等引用语法：必须说明**每个引用参考什么**（首帧、人物、运镜、动作、特效、节奏、音色、BGM），禁止只写「参考 @视频1」。具体语法只用于真实存在、入口认可的素材。其他模型使用其自己的语法。

原案例、社区复测和新提示词是三类证据，不能把原帖标签或复跑效果当作本次新稿/跨模型已验证，不为验证而未经授权重抽。

## 6. 输出可独立使用的完整提示词

澄清或探索阶段只给必要问题、候选方向与明确假设，不硬出完整稿。最终或修订交付先简述关键取舍与未确认项（含相对默认预算是贴边、降密、分段还是显式上调），再给可复制代码块；不让用户拼零散补丁，不并列冲突旧版本。

完整提示词按四块组织（可合并标题，但不缺必要信息）：

```text
【全局】
用途、输入模式、目标时长、构图、整体风格与声音意图；
节拍预算：主动作链数 / 默认（秒数÷5）；若偏离默认，写明上调/降密/分段及理由；
0 秒开场状态与最终结果。

【固定】
全片不变的人物/产品外形、道具数量与归属、固定空间、光线与尺度；
设定锁表（建制与工艺：是什么/不是什么）；
若有参考素材：标识｜继承清单｜不继承清单。

【时间轴】
每段：时间窗｜景别/机位/主运镜（避免中线对称）｜三锚点首句｜
锚人物（若有群体）｜起点状态 → 一个主动作 → 接触与回应 → 结果证据（形变/位移/状态翻转）｜
段末状态句｜环境/拟音/对白/鼓型或配乐变化。
下一段首句必须承接上一段末句同一画面事实；按已确认时长连续覆盖。

【约束】
正向成功标准 + 音源白名单/黑名单 + 避讳词改写要求 + 与本项目相关的少量禁项；
负向清单放在末尾全局生效，不塞进某一段；不沿用无关旧禁令。
```

超默认预算时额外交付（分段与/或降密）：

```text
【叙事总时间轴】全部节拍与因果（可不用于单次生成）
【生成用稿】分段：每条 1—2 个主动作链 + 交接三要素；或单条降密后的拍数与合并说明
```

用户要分镜表时，先给「时间｜画面与动作｜镜头｜声音｜结果证据」，确保与完整提示词一致。字幕、对白、破坏、血腥、风格按当前需求与适用安全要求处理。

## 7. 依据反馈修订

有视频时，先通过实际可用的视频分析能力检查，才记录时间码和视听观察。无法检查则明确仅依据用户描述，不编观片结论。区分用户反馈、实际观察和原因假设，不把猜测当模型内部机制。

优先修复矛盾：最新要求局部破坏就替换旧版无破坏，最新指定喊话就替换无对白。每次交付完整替换稿，解释目标变化，避免不断堆限制。一次满意只代表该次认可，不证明技能通用成功率；不虚构生成结果、耗时、费用或实测。

### 修订时可用的检查维度

| 维度 | 观察什么 |
|---|---|
| 节拍因果 | 每拍能否指出上一拍哪个动作导致本拍开始；相对默认预算是贴边、降密还是分段，有无硬塞 |
| 锚人物 | 每拍画面内能否找到正在执行该动作的具体个体 |
| 结果证据 | 每拍结束是否存在可核验状态差（形变/位移/状态翻转） |
| 节拍顺序 | 要求的关键节拍是否按序出现、时长是否被挤没 |
| 身份/产品 | 脸、服装、几何、颜色、标识是否跨切镜漂移 |
| 设定一致 | 同一建筑材料、门道形制、空间锚点跨段是否不变 |
| 状态交接 | 道具、手、门、天气是否只经可见动作变化；有无段末/段首成对句 |
| 动作/物理 | 主动作是否完成；肢体/物体是否瞬移、合并或数量突变 |
| 空间连续 | 朝向、门槛哪一侧、入城/出城方向是否错乱；有无硬切空档 |
| 声音 | 对白/环境/拟音是否与画面触发对齐；是否出现白名单外音源 |
| 竖屏可读 | 每拍是否保留纵向层次；面部清晰者是否 ≤3 |
| 输出卫生 | 时长、画幅、字幕、水印、多余文字是否符合约定 |

每个问题尽量对应一处可控输入（某一时段、某一固定块、某一素材用途），做有界修改后重交完整稿。

## 8. 常见错误（优先避免）

1. **模糊参考**：有素材却不写参考的是运镜、动作、特效还是节奏。
2. **指令冲突**：同一段同时要求固定镜头与环绕、既静又剧烈甩镜。
3. **内容过载**：4—5 秒塞过多场景或两个主动作各做一半。
4. **只写总时长不写分段**：后半段漂移；或时长声明与分段总和不一致。
5. **逐段重写外形**：诱发换脸换装；应写在固定块。
6. **忽视音频**：无环境声、无拟音触发、对白与音乐抢位；或未写音源白名单导致现代音效穿帮。
7. **负向清单放错位置**：硬限制应在末尾全局块，塞进单段往往只对该段生效或被忽略。
8. **把情绪词当画面**：只写震撼/高级/燃，没有可见状态变化。
9. **伪造素材或能力**：纯文生却写已上传图；或把入口参数当成提示词已生效。
10. **把案例效果当本次验证**：原帖、复测与新稿三类证据不混用。
11. **群体动作不落地**：只写「齐发/齐推」，没有锚人物，群像变摆件。
12. **用氛围当结果**：以冒烟、火光、尘土、溃退代替「形变/位移/状态翻转」，导致关键转折（如破门）缺失。
13. **超默认密度硬塞**：单条提示词塞入远超「秒数÷5」默认预算的节拍，看似完整，实际每拍只剩静态插图；正确做法是分段或降密（或在简案下显式上调并接受风险）。
14. **误读「不擅定数字」**：把叙事量化也删光，导致「大批」坍成最小人数。
15. **段内硬切 / 无接力句**：六段像六段独立素材，靠硬切串起来。
16. **避讳词诱发瑕疵**：门缝白线、火海过曝、穿过城门方向反转、「爆炸」现代音等。

## 9. 交付前自检

- 当前硬要求、默认假设、最新覆盖关系清楚，未误继承旧项目。
- 节拍相对默认预算已处理：落在默认内，或已降密/分段/显式上调并说明理由；未把超密多拍假装成可单次生成。
- 时间连续，关键动作与回应留足余量；完整稿没有要求用户自行填的占位符。
- 每拍有结果证据；群体拍有锚人物；段末/段首成对接力。
- 主体与道具数量稳定，持物、姿态、朝向变化可追踪；固定块与时间轴不互相打架。
- 有世界观时设定锁表完整，跨段形制一致。
- 空间轴线、光线、尺度、接触与因果成立，切镜不掩盖缺失动作；无段内硬切。
- 运镜无冲突，声音有触发点且互不矛盾；音源白名单在约束块；负向清单在末尾且与本案相关。
- 低分辨率时未依赖「千人千面」；分镜表和完整提示词一致，可独立复制。
- 文本意图与平台能力分开，未伪造素材、验证、生成或授权。

## 示例 A：雨后阳台浇花（单人短片）

仅演示结构。假设本次用户已选择 6 秒、竖屏、有环境声、无对白；这些不是默认值、入口设置或能力承诺，示例未经视频生成验证。默认预算：6÷5 → 约 1 条主动作链（本例将浇水写成一条链分三窗承接）。

```text
【全局】纯文本创作，目标 6 秒竖屏生活短片。节拍预算：1 条主动作链（浇水），落在默认（6÷5≈1）内。0 秒进入雨后阳台，一位成年人准备给花盆补少量水，结尾完成浇水并收手。

【固定】同一人穿浅色长袖，右手持唯一白色小水壶；一只陶盆位于木桌中央，叶片带雨珠。晨光从左侧进入，阳台和盆的位置固定。全程人物、服装、壶与盆数量不变。

【时间轴】
0—2秒（侧面中景，固定机位）：壶嘴移到盆沿内侧，左手扶稳盆边，壶未倾斜。远处鸟鸣、衣料轻响。段末：壶嘴停在盆沿内侧，尚未倾倒。
2—4秒（同侧近景）：承接壶嘴在盆沿内侧；右手缓慢倾壶，细水流落在土面，土壤局部逐渐变深（结果：位移+状态翻转）。同步落水声，环境声不断。段末：土面出现深色湿斑，水流仍细。
4—6秒（机位不变）：承接湿斑与细流；水壶回正，水流减细后停止；壶嘴离开，左手松开盆边。停留湿润土面和轻晃叶片，只留鸟鸣。

【约束】移壶、倾倒、回正止水、移开的顺序清晰；手与壶数量不变，水流连接壶嘴与土面。无音乐、对白、字幕，不换植物、陶盆和天气，不用转场遮住动作。
```

## 示例 B：城门破洞入城（大场面节选）

仅演示结构。假设用户已选择 15 秒、竖屏、有环境声与鼓点、无对白、纯文生；历史向冷兵器攻城。默认预算：15÷5 = 3 条主动作链。本例贴默认写 3 拍（撞门破洞 → 步兵涌入 → 骑兵入城），演示锚人物、结果证据、设定锁、音源白名单与避讳词规避。**若叙事需要 6 拍（远程压制→盾墙→云梯→破门→夺楼→骑兵），群戏密度高，应分段或降密，不要塞进单条 15—30 秒提示词冒充可单次生成。** 示例未经视频生成验证。

```text
【全局】纯文本创作，目标 15 秒竖屏历史短剧高光。节拍预算：3 条主动作链，贴默认（15÷5=3）；群戏未上调。0 秒攻城锤队抵近紧闭城门，结尾骑兵自门外亮处冲入城内巷道。整体光向：黄昏侧光自画面左侧。

【固定】
城墙：夯土版筑，可见横向夯层与收分，女墙垛口，不用整齐现代机砖贴面。
门道：过梁式排叉柱撑顶的方形门道与木板门，不用砖拱券；门洞位置与高度全片不变。
攻方：灰褐短甲与红巾；守方：青灰札甲。器械：一门撞木、两侧拉绳队。
低分辨率策略：面部清晰者每镜 ≤3；体量靠旗幡、纵深排数与烟尘方向。

【时间轴】
0—5秒（3/4 斜侧中全景，固定机位，主体偏离中线）：
三锚点——夯土城墙与方形门道、紧闭木门、左侧黄昏光。
锚人物：门前左侧一名红巾短甲兵，双肩前顶撞木尾端，双脚蹬地发力。
起点：木门完整紧闭。主动作：锚人物带动约 30 人撞木队齐推一次（群体只写体量，发力细节在锚人物）。
接触：撞木头撞击门板中下部。结果证据（形变+状态翻转）：门轴崩裂，门板错位向内塌开一道可过人豁口（禁止写门缝/透光白线；禁止以冒火冒烟代替破门）。
段末：豁口已开，门板歪斜内倾，烟尘在门洞左侧；鼓型为「一记重击接长音」，重击落在撞击瞬间。木石撞击与甲片摩擦。

5—10秒（同侧稍推近，仍斜侧，段内无切）：
首句承接：同一豁口、同一歪斜门板、同一左侧烟尘与光向。
锚人物：豁口前一名持刀短甲兵弓身先行踏入门槛。
主动作：其后约两列步兵跟入，旗帜从门外压进门洞。
结果证据（位移）：持刀兵从门外泥地踏到门内石板，旗帜越过门楣线进入城内。
段末：门内可见沿街矮屋轮廓，持刀兵已在门内侧；急鼓行进双击，脚步与甲片声。

10—15秒（镜头改到城内一侧，斜对门洞，主体偏离中线）：
首句承接：同一豁口与歪斜门板（从城内回看），左侧光从门外射入。
锚人物：第一列左侧一名持矛骑兵，马头朝向镜头纵深。
主动作：约 12 骑分两列自门外亮处越入画面、向镜头纵深奔来（禁止含糊写「穿过城门」导致方向反转）。
结果证据（位移+状态翻转）：马匹从门外亮处进入门内暗处街巷，门外仍见攻城队列纵深。
段末：骑兵占据门内通道；三记收束鼓，马蹄声与呼喊。

【约束】
成功：三拍因果可追（撞击导致豁口 → 豁口导致步兵踏入 → 门洞通行导致骑兵自外向内奔来）；每拍有锚人物与结果证据。
音源只允许：战鼓、号角、木石撞击、甲片摩擦、马蹄、火油/竹木噼啪（若出现火）、呼喊、风声；禁止枪炮、自动武器、机械轰鸣、动物咆哮、电子乐、现代爆炸库音。不写「爆炸」。
禁：段内硬切；正对门中线对称构图；用冒烟火光代替破门；门道改成砖拱券；出城方向；换城墙材料。
```
